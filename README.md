# Optimizing Metabolite Production by Manipulating Transcription-Factor Expression

This repository contains a COBRApy/Jupyter workflow for screening transcription-factor
(TF) perturbations that may improve the production of a target metabolite in
*Saccharomyces cerevisiae*. The workflow combines:

- the Yeast8.5.0 genome-scale metabolic model;
- regulatory interactions from YEASTRACT+;
- parsimonious flux balance analysis (pFBA); and
- simulated TF under-expression, knockout, and over-expression experiments.

The analysis can be run with either the model's minimal (Verduyn) medium or a
manually specified rich medium. The main deliverable is the
[TF_Optimization.ipynb](./TF_Optimization.ipynb) notebook.

## Open in Google Colab

If you work with Google Colab, please download and copy this .ipynb to your account.

## Requirements

- Python 3
- Jupyter Notebook or Google Colab
- [COBRApy](https://github.com/opencobra/cobrapy)
- [Lark](https://github.com/lark-parser/lark)
- `wget`, used by the notebook to download its input files

The notebook downloads the Yeast8 model and the YEASTRACT regulation data
automatically. They are not stored in this repository.

## Quick start

1. Clone the repository:

   ```bash
   git clone https://github.com/dalexandre963-cmd/Optimizing-Metabolite-Production-by-Manipulating-TF-Expression.git
   cd Optimizing-Metabolite-Production-by-Manipulating-TF-Expression
   ```

2. Install the Python dependencies:

   ```bash
   python -m pip install cobra lark
   ```

3. Open and run [TF_Optimization.ipynb](./TF_Optimization.ipynb) from top to
   bottom:

   ```bash
   jupyter notebook TF_Optimization.ipynb
   ```

   The notebook downloads `yeast8GEM.xml` and
   `Yeastract-Sc-regs.tsv` when their respective cells run, so no manual data
   download is required. To use different files, update the download and
   model-loading cells before running the analysis.

## Workflow

The notebook performs the following steps:

1. Loads the Yeast8 SBML model twice, keeping separate copies for minimal and
   rich media.
2. Identifies exchange reactions and configures nutrient uptake bounds for
   each medium. Flux bounds are expressed in mmol/gDW/h.
3. Calculates wild-type reference fluxes with pFBA.
4. Parses YEASTRACT regulation data and separates direct/indirect and
   positive/negative TF-target relationships.
5. Evaluates Boolean gene-reaction rules for each simulated perturbation.
6. Applies the corresponding expression changes to the model and compares
   the predicted target-product flux with the wild-type solution.
7. Writes promising flux tables to files named
   `Fluxes_<TF>_<target-group>.csv` when a perturbation improves the reference
   ethanol flux.

## Configuring an experiment

The experiment cell is the main point of customization. In the notebook,
update:

```python
userTF = "PDC2"
tExps = ((0.00, 1.25), (0.00, 1.50), (0.00, 2.00))
```

Each pair represents the simulated expression level of a target gene before
and after the perturbation. A value of `0.00` represents a knockout in the
provided examples; values greater than `1.00` represent increased expression
relative to the reference state. Use a TF name present in the loaded
YEASTRACT data.

Select the medium and its matching wild-type solution in the same cell:

```python
model = modelRichMedium
solWT = solWTRich
```

In the current notebook, pFBA uses the model's biomass objective and
perturbations are retained only when the ethanol exchange reaction `r_1761`
has a higher flux than the wild-type solution. Confirm that `r_1761` and the
biomass objective exist in the version of the Yeast8 model you use. To screen
a different product, update the reaction ID used in the comparison and in the
output messages in the experiment cell.

## Input data

The notebook fetches the following files automatically:

| File | Purpose |
| --- | --- |
| `yeast8GEM.xml` | Yeast8 genome-scale metabolic model in SBML format |
| `Yeastract-Sc-regs.tsv` | YEASTRACT regulation relationships for *S. cerevisiae* |

The download cells currently retrieve both files from the project data server.

Sources for related upstream resources are the
[Yeast-GEM project](https://github.com/SysBioChalmers/yeast-GEM) and
[YEASTRACT+](https://www.yeastract-plus.org/). If you replace either file,
ensure that the identifiers in the regulation data match those used by the
metabolic model.

## Results and interpretation

Generated files named `Fluxes_<TF>_<target-group>.csv` contain the full reaction-flux
tables generated by the notebook for perturbations that improve the
wild-type ethanol flux. Open them with a spreadsheet application or load them
with pandas for further analysis.

These are in-silico flux predictions, not experimental measurements. Results
depend on the model version, exchange bounds, objective reaction, solver,
regulatory dataset, and perturbation parameterization. A predicted improvement
should therefore be treated as a hypothesis for subsequent biological
validation.

## Reproducibility notes

- Run cells in order because later cells use models, solutions, and parsed regulatory dictionaries created earlier.
- Record the selected medium, objective reaction, TF, perturbation pairs, and solver configuration alongside each result.
- If using a different species or metabolic model, update both the input file paths and any identifier-conversion assumptions in the regulation-processing cell.
